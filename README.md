# Heart Disease Prediction Web App

Predicts heart disease risk from 13 clinical features using a Random Forest model.

## Tech
Python, scikit-learn, Flask, HTML/CSS

## Dataset
UCI Heart Disease (Cleveland), 303 records, 13 features

## Run locally
pip install -r requirements.txt
python train_model.py
python app.py
